# 易川 · 发布仓库

本仓库**只存放发布产物**（APK + 更新说明），不含源码。

## 下载

最新版见右侧 [Releases](../../releases/latest)。

## 关于应用内更新

易川 0.1.1 起内置「从 GitHub 拉取更新」：

- 入口：设置 → 关于易川 → 检查更新
- 下载支持断点续传与自动重试；走前台服务，通知栏可见进度、可就地取消
- 安装前校验包名、versionCode 与**签名证书 SHA-256**，不一致直接拒绝
- 只拉起系统安装器，不做静默安装，也不内置任何 token

## 版本约定

| tag | versionName | versionCode |
|---|---|---|
| `v0.1.1` | 0.1.1 | 2 |

新版本的 `versionCode` 必须严格递增，否则系统会拒绝安装。资产文件名统一为 `yichuan-<versionName>.apk`。

## 签名

当前发布包使用开发用 debug 签名，仅用于自测与内部验证；换机或重新编译会导致签名不同，届时需要迁移到正式签名。
