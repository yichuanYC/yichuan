# 易川 · 发布仓库

本仓库**只存放发布产物**（APK + 更新说明），不含源码。

## 下载

最新版见 [Releases](../../releases/latest)。

## 应用内更新

入口：设置 → 关于易川 → 软件更新。

- 从本仓库的 latest release 检查版本，按 `versionCode` 数字段比较
- 下载走前台服务，支持断点续传与自动重试，通知栏可见进度、可就地取消
- 安装前校验包名、`versionCode` 与**签名证书 SHA-256**，任一不符直接拒绝
- 只拉起系统安装器，不做静默安装；应用内不内置任何 token
- 更新日志取 release 正文，按分类条目排版展示，检测到新版本时自动弹一次，之后可在页面上随时重看

## 版本约定

| tag | versionName | versionCode |
|---|---|---|
| `v0.1.1` | 0.1.1 | 2 |
| `v0.1.2` | 0.1.2 | 3 |
| `v0.1.3` | 0.1.3 | 4 |
| `v0.1.6` | 0.1.6 | 7 |

`versionCode` 必须严格递增，否则系统会拒绝安装。资产文件名统一为 `yichuan-<versionName>.apk`。

0.1.1 与 0.1.2 为 debug 签名，与后续正式签名版本证书不同，升级到 0.1.3 及以后需先卸载一次。0.1.4、0.1.5 是内部验收版本，未对外发布。

## 签名

发布包使用固定证书签名，SHA-256 指纹：

```
F7:E2:44:59:7E:00:15:CD:DA:1C:F2:A0:71:2C:57:FC:03:E9:36:73:0B:2B:3A:F6:1E:93:11:75:B4:80:10:20
```

签名变更意味着已安装用户无法覆盖升级，因此该证书长期不变。

## 更新日志规范

发布说明按分类条目书写，分类固定为「新增 / 改进 / 修复 / 注意」，无内容的分类整节省略。单条一句话，句末不加句号，只写用户可感知的变化。
