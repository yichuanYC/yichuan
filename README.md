## 简介

易川在手机本地完成音频文件的解密与容器转换：读取主流音乐客户端下载到本机的加密文件，还原为标准音频文件，全程不联网、不上传、不做二次压缩。除转换外，应用同时提供本地播放器、29 件常用小工具与一套主题系统。

- 识别 KGM / KGMA、NCM、QMC v1、KWM 四类加密格式，覆盖酷狗、网易云、QQ 音乐、酷我
- 按文件实际内容判定容器，输出 FLAC、MP3、WAV、OGG、M4A、AAC、APE、WMA 共 8 种，不按文件名推测
- 转换在本机完成，不发起网络请求，音质不做二次压缩
- 产物统一写入 `下载/易川/`，同名文件自动改名，不覆盖已有文件
- 首页逐条列出四家客户端的目录状态：可读取、缺少权限、目录不存在

## 功能

| 模块 | 说明 |
|---|---|
| 解密转换 | 单条转换与全部转换，进度与结果就地显示；转换由前台服务承载，切至后台不中断 |
| 本地播放 | 后台播放、锁屏与状态栏媒体卡片，播放控制提供三档兼容开关 |
| 小工具 | 29 件，分为提取、实用、趣味、玩机四组，多数无需授权 |
| 主题系统 | 预设配色、深浅色跟随系统、应用图标深浅色切换 |
| 应用内更新 | 多连接分段下载、断点续传，安装前校验包名、版本号与签名 |

## 支持格式

| 平台 | 加密后缀 | 状态 |
|---|---|---|
| 酷狗 | `.kgm` `.kgma` | 支持 |
| 网易云 | `.ncm` | 支持 |
| QQ 音乐 | `.qmc*` `.tkm` `.bkc*`（v1） | 支持 |
| 酷我 | `.kwm` | 支持 |
| QQ 音乐 | `.mflac` `.mgg` `.kgg` | 不支持，密钥不在文件内 |

输出的真实容器为 FLAC、MP3、WAV、OGG、M4A、AAC、APE、WMA 共 8 种；后缀由文件实际内容决定。

## 安装

1. 在 [Releases](../../releases/latest) 下载 `yichuan-<版本>.apk`，点击安装
2. 首次启动按引导授予两项权限：**所有文件访问**（扫描四家客户端目录）与**音乐和音频**（读取文件）
3. 系统要求：Android 10（API 29）及以上

> 0.1.18 起包名由 `com.example.shareapp` 改为 `io.github.yichuanyc.yichuan`。两者是不同的应用，装过 0.1.17 及更早版本的设备需先卸载再安装；旧安装包已全部下线，历史说明见 [CHANGELOG.md](CHANGELOG.md)。

## 怎么用

1. 打开首页，等待扫描结束：待转换一栏列出四家目录中可解密的文件
2. 点某一条的「转换」，或「全部转换」排队处理；进度与结果写在卡片内
3. 产物出现在已转换一栏，点 ▶ 直接播放，点条目进入播放页（支持后台播放与锁屏控制）
4. 两栏默认只显示三行，内容较多时点标题右侧的角标展开
5. 需要用其他应用播放或管理文件：设置 → 存储与缓存 →「打开」，列出全部产物，点一条交系统播放器打开

## 应用内更新

入口：设置 → 关于易川 → 软件更新。

- 从本仓库的 latest release 检查版本，按 `versionCode` 数字段比较
- 支持跨版本升级：只比较 latest 与本机，中间隔若干版本均可一步升至最新
- 下载走前台服务，多连接分段下载（线程数可在软件更新页设为 2/4/8/12/16，默认 8），支持断点续传与自动重试
- 下载源分三档：直连优先 / 加速优先（自建反向代理）/ 镜像优先（公共镜像，需确认一次）
- 安装前校验包名、`versionCode` 与**签名证书 SHA-256**，任一不符即拒绝
- 仅拉起系统安装器，不做静默安装；应用内不内置任何 token

## 隐私与联网

- 转换、播放与全部工具均在本机运行，不收集使用数据，不要求账号，不上传文件
- 应用仅在两处联网：检查并下载更新；「去水印」工具从平台公开接口解析直链
- 更新下载走前台服务，应用内不内置 token、密钥或第三方统计 SDK
- 扫描结果与转换产物只保存在本机

## 签名

发布包使用固定证书签名，SHA-256 指纹：

```
F7:E2:44:59:7E:00:15:CD:DA:1C:F2:A0:71:2C:57:FC:03:E9:36:73:0B:2B:3A:F6:1E:93:11:75:B4:80:10:20
```

签名变更意味着已安装用户无法覆盖升级，因此该证书长期不变。

## 限制说明

- 本应用只完成解密与容器转换，不解 DRM，不提供任何会员或付费内容的获取能力
- `.mflac` / `.mgg` / `.kgg` 无法解密，密钥不在文件内
- 部分国产 ROM 的状态栏媒体卡片需在「设置 → 高级功能 → 播放控制」中切换档位
- 高采样率（96/192 kHz）与多声道输出依赖系统播放器的重采样与下混
